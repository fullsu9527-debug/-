# 多版本高中物理例题资源研究平台

一个纯 **HTML + CSS + JavaScript** 的单页交互式研究网页，配套硕士学位论文。
它以六版必修一全部 **95 道教材例题**的**六维编码总表（D1–D6）**为唯一数据源，
把例题资源做成可筛选、可统计、可整合、可拓展的研究工具。

> 设计基调：专业 · 克制 · 研究感。六版本识别色与认知层级Ⅲ的红色对应论文语义，
> 不作含义改动。

## 六个页面

| 页面 | 作用 |
|------|------|
| **首页** | 结论先行：核心发现卡片 + 研究主线（素材→发现→聚焦→对策一→对策二） |
| **原题库** | 95 道例题，可按版本 / D1 情境 / D2 模块 / D6 层级与关键词筛选 |
| **文本分析** | 版本×情境、版本×层级堆叠图，模块×情境热力图，认知层级金字塔（可点击回查例题） |
| **横向切片** | 交通制动安全模型的「版本×层级」矩阵与切片例题 |
| **整合策略** | 跨版本整合决策工作台（情形一/二）与题干要素抽取组合器 |
| **拓展策略** | 以任意母题按 D1–D6 定向生成变式的工作台（含浏览器端 OCR 实验） |

## 六维编码（D1–D6）

D1 情境类型 · D2 知识模块 · D3 图示类型 · D4 呈现结构范式 · D5 助学栏目功能 · D6 认知层级。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需服务器或联网。

- 必须保持 `index.html` 与 `images/`（173 张例题截图）在同一目录。
- 图片为相对路径 `images/img-XXX.png`，迁移时请连 `images/` 一起带走。
- **OCR 功能**需要联网（从 CDN 加载 tesseract.js 引擎），其余功能完全离线可用。
- OCR 校对文本与要素编辑结果保存在浏览器 **localStorage**，不上传服务器，
  不同环境之间不互通属正常现象。

可选：用任意静态服务器获得更接近线上的体验，例如
`python3 -m http.server` 后访问 `http://localhost:8000`。

## 已加入的网站化增强（v7 系列）

在保留全部功能、数据、统计与语义识别色的前提下，做了视觉与体验打磨：

- **视觉**：坐标纸网格底纹、收敛阴影、编号徽章、列表/卡片悬停反馈、图表色例。
- **信息架构**：结论先行首页、研究主线导览、每页过渡语与「下一步」顺序浏览。
- **真实网站骨架**：
  - **URL 路由**——每页有自己的 `#hash`，支持刷新保留、前进/后退、书签分享，标签标题随页面更新；
  - **移动端导航**——汉堡菜单（窄屏下可正常使用）；
  - `favicon`、`description`、Open Graph / Twitter 分享卡、站点页脚。
- **看题体验**：弹窗内 ← / → 翻题与「i / N」位置指示、截图全屏放大（适应窗口 / 原始分辨率）。
- **可分享状态**：
  - `#library?v=人教版&d6=Ⅲ`（筛选后的题库）；
  - `#extension?m=RJ-04&d=d6`（某道母题的变式工作台）；
  - 工具栏「🔗 复制筛选链接」。
- **收尾细节**：`<noscript>` 友好提示、跳到主内容、模态无障碍属性、图片加载态、
  打印 / 导出 PDF 样式、`prefers-reduced-motion` 支持。
